SMRITI CARE (Neuro Mind)

App Working, Tech Stack & Workflow Guide

1. App Kya Hai? (Introduction)

Smriti Care (Neuro Mind) ek AI-powered platform hai jo mainly older adults (buzurgon) ki memory aur cognitive health (dimaghi sehat) ko improve karne ke liye banaya gaya hai.

Is app mein memory games (jaise Match 3, Jigsaw, Sudoku, etc.) hain jo brain ki exercise karate hain. Sath hi isme caregivers (dekhbhal karne wale) aur doctors ke liye bhi features hain jisse wo patient ki progress track kar sakein. Isme North-Eastern languages (Assamese, Manipuri, Khasi, Mizo) ko bhi support kiya gaya hai taaki local log apni bhasha mein ise use kar sakein.

2. Tech Stack (Kaunsi Technologies Use Hui Hain?)

Frontend (Jo User Ko Dikhta Hai)
  • React 19 & Vite: App ka UI banane ke liye. Vite isko super fast banata hai development aur build time mein.
  • TypeScript: JavaScript ka advanced version jo code mein errors kam karta hai by adding "types".
  • Tailwind CSS: App ki styling (colors, layout) ke liye use hua hai. Ye directly HTML/TSX classes mein likha jata hai (e.g., text-xl bg-blue-500).
  • Zustand: Global state management ke liye. Jaise ki kaunsa user logged in hai, wo data poore app mein maintain karne ke liye (authStore, uiStore).
  • React Router DOM: Pages ke beech navigation ke liye (jaise Home se Games page par jana).
  • i18next: Multi-language support (i18n) ke liye. Jab user bhasha badalta hai, toh poori app instantly translate ho jati hai bina page reload hue.
  • Framer Motion: Smooth animations aur transitions ke liye jo app ko premium feel dete hain.
  • PWA (Progressive Web App): Iski madad se website ek mobile app ki tarah phone mein install ho sakti hai aur offline/slow internet mein bhi cache ki wajah se chal sakti hai.
Backend (Jo Data Handle Karta Hai)
  • Node.js & Express: Server banane ke liye aur API endpoints (jaise /api/login) ko handle karne ke liye.
  • Prisma ORM: Database se baat karne ka tool. Isse hume direct SQL queries nahi likhni padti, balki Prisma ka asaan code likhna padta hai (e.g., prisma.user.findMany()).
  • PostgreSQL / SQLite: Database jahan saara data (users, scores, notes) save hota hai. Local testing mein SQLite use hua hai, aur cloud (Antideploy/Render) par PostgreSQL.
  • JWT (JSON Web Tokens): Security aur login sessions manage karne ke liye. Jab user login karta hai toh ek token milta hai jisse wo securely private data access kar pata hai.

3. App Ka Workflow (App Kaam Kaise Karti Hai?)

A. User Roles (4 Tarah Ke Users Hain)

  • Patient: Inka dashboard bahut simple aur aasan hota hai. Inhe PIN se login karvaya jata hai (kyunki passwords yaad rakhna mushkil hota hai). Inko Games khelne hote hain aur apni feelings (mood) track karni hoti hai.
  • Caregiver: Ye wo log hain jo patient ka dhyan rakhte hain. Ye patients add kar sakte hain, unke liye reminders (davai, khana) set kar sakte hain aur unke game scores dekh sakte hain.
  • Doctor: Doctor patients ki history, unke clinical reports aur cognitive progress graphs dekhta hai aur notes add karta hai.
  • Admin: System ke sabhi users aur games ko manage karta hai.

B. Step-by-Step App Workflow

1. Authentication (Login / Signup):
Jab user website kholta hai, wo apna role (Patient, Caregiver, Doctor) select karke login karta hai. Frontend API ko request bhejta hai, backend verify karke ek JWT token deta hai jo browser ke local storage mein save ho jata hai (Zustand authStore ke through).
2. Patient Dashboard & Games:
Patient login hone par PatientLayout load hota hai. Yahan badi screen par "Activities" aur "Reminders" dikhte hain. Jab Patient "Games" par click karta hai, toh list aati hai (Memory Match, Jigsaw). Har game React components se bana hai jo user ka time, score aur accuracy track karta hai.
3. Voice Instructions (Text-To-Speech):
App mein "Speaker" icon hai. Jab user us par click karta hai, app ka GameEngine.tsx browser ki native Web Speech API ko use karta hai. Jo language select ki gayi hai (jaise Hindi, English), app usi aawaz mein text ko padh kar sunati hai.
4. Data Saving & Sync:
Game khatam hone par, frontend ek request /api/game-sessions par bhejta hai. Backend Prisma ke zariye is data ko database mein save kar leta hai, taaki baad mein doctor ya caregiver uski report dekh sake.
5. Caregiver & Doctor Reports:
Caregiver apne dashboard par jata hai toh backend se un patients ki list aati hai jo unse linked hain. Doctor PDF ya CSV format mein patient ka data download kar sakte hain, jisse ye pata chalta hai ki patient ki memory weak ho rahi hai ya improve ho rahi hai.

4. Hosting & Deployment (Cloud Par Kaise Rakha Hai?)

Ye ek Monorepo hai jismein client aur server dono ek hi jagah hain.

  • Backend API: Antideploy par host kiya gaya hai jo automatically Node.js server aur PostgreSQL database run karta hai.
  • Frontend Web: Ye bhi Antideploy par host kiya gaya hai. Iska API URL (VITE_API_URL) hamare deployed backend ki taraf point karta hai.
